# Support & Community

Welcome to the Kairos community! We are excited to have you here.

## Getting Help

### 1. Documentation
Before opening an issue, please review:
* [README.md](README.md) — Architecture, installation, and usage instructions.
* [CONTRIBUTING.md](CONTRIBUTING.md) — Guidelines for building and contributing.

### 2. GitHub Issues
If you encounter a bug or have a feature request:
* **Bug Reports:** Search existing issues to ensure it hasn't already been reported. If not, open a new bug report using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.yml).
* **Feature Requests:** Share ideas and proposals using our [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.yml).

### 3. GitHub Discussions
For general questions, design ideas, or architectural discussions, join our GitHub Discussions forum (when enabled on the repository).

### 4. Security
For sensitive security vulnerability reports, refer to [SECURITY.md](SECURITY.md) and email `kachakaran06@gmail.com`.
